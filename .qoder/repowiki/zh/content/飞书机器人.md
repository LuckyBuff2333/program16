# 飞书机器人

## 引用文件
- `src/clients/feishu_client.py` — 飞书 API 客户端
- `src/api/routes/feishu.py` — 飞书相关路由
- `src/web/server.py` — 机器人会话管理

---

## 功能架构

飞书机器人功能拆分为三部分：

| 模块 | 说明 |
|------|------|
| 基础信息修改 | 修改 Jira 单的基本信息 |
| 单次执行 | 执行一轮分析任务 |
| 持续执行 | 多轮自动循环，可被中断 |

---

## 持续执行机制

### 输入格式
用户输入 `每批数量,间隔分钟,执行轮数`，例如 `20,30,5` 表示每批20条、间隔30分钟、执行5轮。

### 核心机制
- 会话状态（`_bot_sessions`）、运行任务标记（`_bot_running_tasks`）、取消信号（`_bot_cancel_events`）均存储在**进程内存**中
- 由 `threading.Thread(daemon=True)` 守护线程处理
- 状态不持久化、不跨机器共享

### 参数覆盖逻辑
- 实际抽取数量以 session 中保存的 `batch_count` 为准
- 后续 JQL 指令中的数量参数会被 session 覆盖
- JQL 编号和执行模式（PC/线上）仍按最后输入生效

### 部署限制
- 任务一旦在某台机器启动，后续轮次均由该机器完成
- 其他机器无法接管或影响该任务
- 执行机器宕机则任务丢失，无法恢复
