# Bug 5005 日志分析报告

## 根因结论
JVM老年代内存泄漏导致频繁Full GC引发服务超时

## 问题触发时间
2026-08-13 16:20:00

## 关键日志依据
- 2026-08-13 16:18:42 [WARN] order-service - JVM 老年代使用率从 75% 持续增长至 89%，堆内存回收效率下降
- 2026-08-13 16:19:36 [WARN] order-service - Full GC 耗时 4.8s，回收率不足 8%，堆内存持续增长不回收
- 2026-08-13 16:20:04 [ERROR] order-service - JVM 堆内存溢出 java.lang.OutOfMemoryError: Java heap space，进程崩溃重启
- 2026-08-13 16:20:08 [ERROR] gateway - 下游 order-service 不可用，请求超时率 95%
- 2026-08-13 16:20:15 [WARN] monitor - order-service 进程已重启，JVM 堆内存重置

## 分析步骤
1. 排查订单服务JVM内存使用情况，发现老年代使用率持续增长不回收
2. 分析GC日志，确认Full GC频繁且回收率极低，存在内存泄漏
3. 定位到OrderExportCache持有大量历史数据未释放，确认为内存泄漏点
4. 修复缓存清理逻辑并增大堆内存配置，服务重启后恢复正常
