- **已确认的事实**：DM 语义模型将“随机轮换”的 mode 槽位解析为 `NOT_SUPPORT_MODE`（AI日志L106045），导致语音服务返回 result:1013 拒绝执行（L106143）；ASR 识别正常（L88419），RPC 链路本身无异常（对比L276617/L518782）；最终在0128版本实车验证通过。

- **与AI日志分析结论的一致点和差异点**：一致点在于均确认根因是 DM 语义模型映射缺失导致 `NOT_SUPPORT_MODE`，且 ASR 与 RPC 链路正常。差异点在于 AI 分析强调“语义解析耗时异常”为重要线索，而 Jira 评论中未提及该耗时问题，且评论显示最终通过版本验证解决，未明确说明是否修复了耗时问题。
