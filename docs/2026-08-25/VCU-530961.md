## **⑤ 修复建议**

**代码级建议（优先）**

在 `onCrossImageVisibleChanged` 回调中增加 bitmap 就绪检查，当 mBitmap 为空时延迟显示，等待截图完成回调后再触发悬浮窗显示：

```1
// 伪代码示例
void onCrossImageVisibleChanged(boolean visible) {
    if (visible) {
        if (mBitmap == null) {
            // 等待截图完成，暂不显示
            pendingShow = true;
            return; // 或注册截图完成监听
        }
        showCrossImage(mBitmap);
    }
}

// 截图完成回调中补充触发逻辑
void onScreenshotComplete(Bitmap bitmap) {
    mBitmap = bitmap;
    if (pendingShow) {
        showCrossImage(mBitmap);
    }
}
```

**配置级建议**

- 在截图完成回调中补充日志（如 `onScreenshotComplete`/`setBitmap`），确保截图完成后主动触发悬浮窗刷新，避免渲染空白帧

**排查方向**

- 排查地图截图模块的异步回调链路，确认截图完成事件是否正确通知到 SR 悬浮窗服务

- 建议补充日志：截图完成回调的时间戳、bitmap 填充时机、以及 onCrossImageVisibleChanged 中 mBitmap 为空时的具体渲染路径（是直接渲染空白还是跳过渲染）
