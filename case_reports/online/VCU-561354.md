- **根因**: QQ音乐通过 MediaSession 上报的专辑图 URI 固定为 QQ音乐 CDN 的 **120x120 px 低分辨率规格**（URL 中 `T002R120x120M` 的 `R120x120`），媒体服务（`com.patac.hmi.media`）在 `NormalState.updateAppwidget2x2` → `loadHttpImage` 中**直接透传该 URI，未做任何尺寸替换或高清图请求**，导致 120x120 源图在 130x130 的 `ivAlbumView` 控件上显示模糊。
- **因果链**: QQ音乐 MediaSession 上报 R120x120 专辑图 URI → 媒体服务 `updateAppwidget2x2` 取 `mediaData.albumUri` 直接透传给 `loadHttpImage`（同线程同毫秒，无拼接日志）→ AppWidget 下发 120x120 图 → Launcher `ivAlbumView`（130x130）显示 → 源图分辨率不足 + 轻微放大 → 显示模糊。
- **关键证据**:
  - `10-27 16:01:37.119 4705 8589 D com.patac.hmi.media-NormalState: loadHttpImage mCurrentAlbumUri:https://y.gtimg.cn/music/photo_new/T002R120x120M000001xWVat25UFRD_2.jpg`（源图 120x120）

  - 全日志 `gtimg.cn` 仅出现 R120x120 一种规格，无 R500x500/R800x800（负向证据：从未请求高清图）
