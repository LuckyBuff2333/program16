# 知识沉淀原则（正本）

> 本文件是本技能知识沉淀纪律的**唯一正本**——技能各阶段凡涉及"沉淀知识"的动作，一律遵守本文件，禁在别处另立副本（双源必漂移）。
> 适用对象：从日志分析过程（判读/复核/泛解析）产出的一切知识资产——架构文档、数据字典、案例档案、知识草稿。
> 一句话总纲：**知识库叙述系统正常运行时的样子；个案发生了什么，归案例与待确认清单。**

## 一、视角原则（写给谁看）

1. **业务方视角写作**：知识本体的写作视角=业务用户本人，不是分析智能体的取证视角。架构知识叙述业务架构（子系统构成/职责/流程/数据含义/业务行为），数据字典陈述业务数据含义。
2. **取证语言不入本体**：检验签名表、断点行注记、证据缺口注记、"客户确认根因侧"类案件结论话术、来源与分级标注章节——分析过程产物不进知识本体。
3. **真实业务粒度**：命名从简（主题词即可，禁"——XX类现象"式后缀）；不写"业务动作的日志行/观测口径"章节（业务用户整理不到这个粒度）；日志 TAG 仅作为身份信息随文内联；机制不设专章，含义并入参数语义或业务行为叙述。

## 二、内容原则（写什么/不写什么）——核心

4. **应有态而非个案态**：知识本体叙述系统**原本应该怎样运转**（构成/职责/流程/字段语义/设计行为），不是本次分析观测到了什么异常。三条禁令：
   - **禁把个案观测写成系统事实**——尤其当该观测本身就是待判定缺陷时（一旦写入=把缺陷固化成设计，后续同类分析将据此判"正常"）
   - **禁以失败分支日志行代替机制叙述**——写机制的应有行为（"账户就绪后才发起下载"），不写失败时打印什么；失败签名归案例档案
   - **禁用"观测取值/实测为/出现在…时"占位未确认语义**——字段存在与归属可写，推断出的值含义不写（推断值入本体=伪事实）
5. **写作闸门自检句**：每句话问——"**这句话在系统正常运行时也成立吗？**"只在本 case 成立=不入知识本体。再加一问："换同域另一个 case，这句话还一样吗？"
6. **案件结论归位**：个案根因裁定与修复决策归案例档案（案例体裁可承载分析结论与签名反查，不受应有态约束——这是案例的天然属性）。若无案例库，暂存"待确认清单"，不入知识本体。
7. **词汇桥优先**：报单用语↔日志语言的映射（模块名↔进程包名、现象口语词↔TAG/接口名）是知识沉淀的最高价值产出，优先进结构化对照表/数据字典。

## 三、未知的诚实处理

8. **不猜不编**：拿不准的业务语义（码表/阈值/接口归属/设计意图）保持"存在、语义未收录"的诚实标注，转知识供给需求单向业务方确认——不靠模型推断占位。
9. **需求单四类框架**：向业务方索取知识按四类组织——**A 业务架构**（模块职责/依赖方向）、**B 业务链路**（完整环节序列/多入口差异）、**C 状态数据**（码表/值域/默认值/合法变化顺序）、**D 功能与日志 TAG 映射**（用语↔包名↔TAG↔控件对照）。需求单只写业务事实问题，不写判断与排查建议。

## 四、组织原则（怎么放）

10. **一主题一篇**：架构文档一主题一篇；现象-机制鉴别诊断一现象族一篇（按现象词直查命中，禁设索引/路由层）；案例归案例库。
11. **结构化数据归表**：具体 ID/信号名/错误码值/属性号是"数据"不是"知识"——收进数据字典按行维护（含来源与验证日期列），禁进文档正文。

## 五、流程原则（怎么入库）

12. **人工审核闸**：入库/上传动作即审核闸——素材清单、机器产出的草稿必须经人工确认后才入正式知识库，禁自动入库。
13. **留痕**：知识变更先落变更说明（改什么/为什么/影响面）再入库，供后续对齐。
14. **双供给线互补**：跟着分析走的草稿（面窄随案）与跟着缺口走的定向沉淀（面广定向）是两条供给线，都受本文件约束。

## 六、泛解析工具特有纪律

15. **触发判据三条 + 成本意识**：冷域（知识库检索零命中）+ 高频域（平台级/多场景共享实体，一次沉淀受益面乘 N）+ 缺口密集（多条缺口只有日志语料能填）——三条全中才值得做，由使用者拍板，工具不自发触发。
16. **素材≠知识件**：泛解析产出的是素材清单（TAG 分桶/去重样本/对照），入库前必须过上述一~五组原则过滤。
17. **关键词取宽**：分析过程用过的词正是检索面窄的盲区来源——扫描关键词应取缺口清单实体 + 报单结论用语 + 同族扩展（同场景客户端族/同名 Gateway 族）。

## 附：素材 → 知识件过滤流程（操作顺序）

```
泛解析素材清单
  → 过原则 4/5（应有态三禁令 + 自检句）：个案观测/失败签名 → 剔除，转案例档案或待确认清单
  → 过原则 8（未确认语义）：码表/阈值/接口归属未确认 → 标"未收录"，转需求单
  → 过原则 7/11（词汇桥/数据归表）：映射类 → 数据字典行；叙述类 → 架构文档篇
  → 过原则 12/13（审核闸 + 留痕）：人工确认 → 入库
```
