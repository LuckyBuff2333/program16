测试以 pytest 为执行框架，`conftest.py` 通过两个 `autouse=True` 夹具提供隔离环境：`fresh_db` 用 `tmp_path` 创建独立 SQLite 并调用 `db.init_db` 初始化空库；`isolated_output` 通过 `monkeypatch` 将配置中的 `doc_dir/report_dir/log_dir` 重定向到临时目录，避免报表合并模式下的跨用例污染。各 `test_*.py` 文件按被测模块划分：`test_db.py` 验证 bugid 只读去重查询；`test_filter.py` 验证评论 Agent 的步骤提取；`test_similarity.py` 验证文本余弦相似度、步骤比对与根因命中判定；`test_audit.py` 使用原始 SQL 建表 `kb_analysis` 模拟知识库记录，验证随机抽查与审核报表生成；`test_pipeline.py` 作为端到端入口，调用 `pipeline.run_pipeline/retry_bug/store_bug` 并断言 CSV 结论报表与数据库状态。所有测试均通过 `@allure.feature` / `@allure.story` 装饰器标注功能与场景，便于生成 Allure 报告。
